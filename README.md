# ✈ ICN 특가 레이더

인천에서 출발하는 항공권, 국내선, 호텔 할인 소식을 한곳에 모아 보는 개인용 페이지입니다.

**👉 [페이지 바로 보기](https://theddack.github.io/icn-air-deals/)**

## 무엇을 볼 수 있나요

첫 화면에서 도시·나라·항공사로 검색하거나 인기 목적지를 누르면 바로 해당 할인으로 갑니다.

| 칸 | 내용 |
|---|---|
| 곧 마감되는 할인 | 판매 마감이 7일 안에 다가온 행사를 가까운 순으로 3건 |
| 지역별 최저가 | 일본 · 중화권 · 동남아 · 미주·유럽·대양주 · 국내로 묶은 최저가와 할인 소식 수. 누르면 아래 목록이 그 지역만 |
| 할인 소식 둘러보기 | 항공권 · 국내선 · 숙박 할인 행사를 **진행 중 · 곧 마감 · 새로 나옴 · 판매 예정 · 마감**으로 나눠 보여줍니다 (해외 호텔은 시범 운영) |
| 가격으로 보기 | 땡처리닷컴 판매가와 Secret Flying 게시 가격을 나란히 |
| 출발 시간표 | 인천공항 출발 항공편과, 그 항공사가 진행 중인 할인 행사 |

행사 카드는 탑승권 모양으로, 왼쪽에 목적지와 할인, 오른쪽에 판매 마감과 기간을 둡니다. 정보마다 출처를 **항공사 공식(메일 인증) · 판매처 가격(땡처리닷컴) · 게시 당시 가격(Secret Flying) · 뉴스 기사**로 구분해 표시합니다.

## 어떻게 모으나요

- 하루 4번(오전 7시, 낮 12시, 오후 6시, 밤 10시) 뉴스 기사를 자동으로 확인합니다.
- 같은 행사를 다룬 기사 여러 건을 하나로 묶고, 기사 제목에서 판매 기간·할인율·노선을 뽑습니다.
- 출발 시간표는 인천국제공항공사 공공데이터를 씁니다.
- "땡처리닷컴 판매가"는 땡처리닷컴에 올라온 인천 출발 땡처리 항공권을 하루 한 번 모아 도착지별 최저 총액·출발 기간·링크만 보여줍니다.
- "Secret Flying 게시 가격"은 Secret Flying에 공개로 올라온 서울 출발 특가를 하루 한 번 모아 노선·가격·링크만 보여줍니다. 가격은 게시 당시 기준이며 항공사가 확인한 가격이 아닙니다.
- AI가 아니라 정해진 규칙으로 처리합니다. 그래서 기사에 없는 내용을 지어내지 않고, 모르는 값은 "미확인"으로 둡니다.

## 이용 전에 알아두세요

- **정보만 제공합니다.** 항공권·숙박을 팔거나 예약을 대신하지 않으며, 소개된 항공사·호텔·언론사와 제휴 관계가 없습니다.
- **뉴스 기사를 바탕으로 자동 정리한 정보라서 틀릴 수 있습니다.** 예약 전에는 반드시 항공사·호텔 공식 홈페이지에서 확인하세요.
- **남은 좌석이나 실제 결제 가격은 보여주지 않습니다.** 공개된 자료로는 알 수 없기 때문입니다.
- 항공사 홈페이지를 직접 긁어 오지 않으며, 사이트의 접근 차단을 우회하지 않습니다.

## 저작권

기사의 저작권은 각 언론사에 있습니다. 이 페이지는 기사 제목과 원문 링크만 보여주고 기사 본문은 저장하지 않습니다.
